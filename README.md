# 🔍 WebSource-View

基于JavaScript的源码查看和下载插件

## ✨安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)(若您已经安装请忽略该步骤)
   
2. 点击蓝字进行安装 [插件](./WebSource-View.js)
  
3. 完成安装，建议阅读以下内容

## ❤️使用教程
单击页面右下角(初始位置)显示放大镜的图标即可在新标签页面查看源码。

单击源码页面右上角的下载图标即可下载Html文件。长按源码进行复制。

长按并拖动显示放大镜的图标即可移动图标位置。

## 🎨语法高亮显示

增加了源码页面的正则语法高亮显示。

具体效果请自己体验，不多做描述。

## 🚫 黑名单

以下页面(搜索引擎页面)不会出现源码查看按钮: 
 / Bing / Yandex / DuckDuckGo / Google / Yahoo / Baidu / Sougou / 

## 🛠兼容

可以运行在以下场景

1.自带脚本管理的浏览器

2.安装了脚本管理器拓展的浏览器(如Tampermonkey)

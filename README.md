# 🔍 WebSource-View

基于JavaScript的源码查看和下载插件

## ✨安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)(若您已经安装请忽略该步骤)
2. 点击蓝字进行安装 [插件](./mobile-source-viewer.user.js)
3. 完成安装，建议阅读以下内容

## 🎨语法高亮显示

HTML 标签 |`#569cd6`|| 
属性名 |`#9cdcfe`|| 
属性值 / 字符串|`#ce9178`|| 
注释 |`#6a9955`斜体 || 
JS 关键字 |`#c586c0`|| 
JS 内置对象 |`#4ec9b0`|| 
JS 方法 |`#dcdcaa`|| 
数字 / 颜色值 |`#b5cea8`|| 
CSS 属性 |`#9cdcfe`|| 
CSS 选择器 |`#d7ba7d` |

## 🚫 黑名单

以下页面(搜索引擎页面)不会出现源码查看按钮: 
 / Bing / Yandex / DuckDuckGo / Google / Yahoo / Baidu / Sougou / 

## 🛠兼容

可以运行在以下场景

1.自带脚本管理的浏览器
2.安装了脚本管理拓展的浏览器(如Tampermonkey)
